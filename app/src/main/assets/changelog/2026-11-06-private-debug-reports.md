Private debug reports

Setup now has an optional debug card. When enabled, a Flag failure button on each main screen and the alarm screen lets you review a local action log, add a note, remove captured images or barcodes, and share a ZIP yourself. Typed field text has its own switch, off by default; the initial text hook covers submitted food text. Images are not redacted, so review them carefully. Nothing is uploaded automatically. Turning debug off clears its local history.
